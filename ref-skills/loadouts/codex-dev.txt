# Personal Codex load-out — deliberately the SMALLEST of the three.
#
# Codex injects the name+description of every discovered skill into the system
# prompt and caps that block at 2% of the model's context window (~5,440 chars
# at 272k; 8,000 when the window is unknown). Over the cap it SHORTENS
# descriptions before it omits skills — and these descriptions carry their
# trigger phrases at the end, so truncation eats exactly the part that decides
# whether a skill fires. A trimmed list beats a truncated one.
#
# Codex documents the cap as "2% of the model's context window, or 8,000
# characters when unknown" (learn.chatgpt.com/docs/build-skills, 2026-10-02); the
# unit of the 2% is not stated, so treat 8,000 chars as the working ceiling.
# Measured 2026-10-02 from the repo: these 11 names + descriptions total ~5.9k bytes.
# Everything else is still on disk and reachable by
# path: read ~/.conan-agent-skills/<name>/SKILL.md and follow it. The load-out
# governs automatic triggering, not availability.
#
# Chosen for what Codex is actually used for here: enterprise BI/multi-tenant
# work, remote/production hosts, and long delegated runs.
